## 1. VISIÓN ESTRATÉGICA (The Master Workflow)

Ember evoluciona hacia un **Ecosistema de Trabajo Contextual** basado en 5 pasos maestros:

2. **Gestión de Artefactos**: Inyección de medios y datos con descripciones para la IA.
3. **AI Context Builder**: Generación de conocimiento para Claude/GPT/DeepSeek.
4. **Refinamiento Visual**: Ajuste en tiempo real vía Inspector.
5. **Exportación e Iteración**: Renderizado broadcast y ciclo de mejora continua.
