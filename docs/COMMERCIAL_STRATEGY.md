# Ember Motion Studio — Commercial Strategy & Positioning

> Fuente de verdad para el marketing, posicionamiento comercial y *killer features* del producto.
> **Versión:** 1.0.0

---

## 1. El Target (Público Objetivo)

El software está dirigido a **cualquier persona que necesite animaciones superpuestas de alta calidad para video**, específicamente:

- **Streamers y Creadores de Contenido:** Necesitan marcos (overlays), alertas y transiciones dinámicas ("marcos bonitos" y responsivos).
- **Editores de Video y Fotógrafos Profesionales:** Necesitan introducciones de alto impacto (ej. videos de pasarela, bodas, fashion films), lower thirds corporativos y gráficos de nivel *broadcast*.

## 2. El "Endgame" (Objetivo de Conversión)

El embudo de conversión es simple y directo:

1. Ver el *reel* / clip promocional.
2. Interesarse por la calidad visual (*Vibe Motion*).
3. Visitar la web oficial (ej. `embermotion.com` o el repo/landing).
4. **Descargar la herramienta.**

## 3. Killer Features (Variables Comerciales)

Estas son las características técnicas traducidas a valor comercial para el usuario final:

### A. VIBE MOTION (Fluid Physics & Aesthetics)

*La característica estrella de marketing.*

- **Qué es:** El sistema matemático de curvas Bezier, físicas de resorte (springs) y *easing* determinista.
- **Valor comercial:** Las animaciones no se sienten "rígidas" ni genéricas. Tienen un *vibe* premium, rebote natural y flujo cinematográfico inmediato, sin tener que animar fotograma a fotograma en After Effects.

### B. KNOWLEDGE BRIDGE (AI-Native Workflow)

- **Qué es:** El generador automático de PDFs con la API del motor.
- **Valor comercial:** Arrastras el manual a tu IA favorita (ChatGPT/Claude), le pides lo que quieres, y te escupe el código del plugin perfecto al primer intento (*One-Shot*). No tienes que saber programar para crear gráficos complejos.

### C. BROADCAST-GRADE DETERMINISM (Cero Drift)

- **Qué es:** Renderizado matemático atómico (framerate perfecto).
- **Valor comercial:** Si el lower-third dura 5.00 segundos, dura *exactamente* 5.00 segundos en el video final. Renderizado impecable, compatible con ProRes y canales Alpha (transparencia real).

### D. ZERO-BUNDLE PLUGIN ECOSYSTEM

- **Qué es:** Arquitectura basada en la web (HTML/CSS/JS) sin compilación pesada.
- **Valor comercial:** Ecosistema abierto. Si puedes maquetar una web, puedes hacer un gráfico para televisión. Plantillas infinitas y ligeras.

---

## 4. Estructura de Mensajes para Promoción (Textos Persistentes)

Para los cierres de videos y material promocional, usar esta jerarquía de información:

1. **Tagline principal:** `AI-NATIVE BROADCAST STUDIO`
2. **Pilar de diseño (Vibe):** `POWERED BY VIBE MOTION`
3. **Pilar técnico:** `TRANSPARENCY & ALPHA EXPORT`
4. **CTA (Llamado a la acción):** `AVAILABLE FOR WINDOWS` + `URL OFICIAL`

> **Nota Interna:** "Vibe Motion" se establece como una *Killer Feature* fuerte a nivel de marca porque conecta emocionalmente con el target (creadores/editores que buscan que su video transmita el "vibe" correcto). Técnicamente se respalda por las utilidades matemáticas avanzadas del motor (ctx.utils).
