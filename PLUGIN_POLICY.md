# Política de Ecosistema y Plugins - DVGE

Esta política regula el desarrollo, distribución y propiedad de las extensiones y complementos (en adelante "Plugins") para el motor DVGE.

## 1. Propiedad Intelectual de los Plugins

A menos que se acuerde lo contrario por escrito, **Jonatan Barón** se reserva la propiedad intelectual y los derechos de explotación de todos los plugins desarrollados para el ecosistema oficial de DVGE.

Cualquier contribución de terceros al repositorio oficial de plugins o al core del motor implica la cesión de derechos necesaria para que Jonatan Barón pueda distribuir, modificar y gestionar dichas extensiones como parte integral del producto DVGE.

## 2. Responsabilidad de Terceros

DVGE permite la carga de plugins externos. Jonatan Barón no se hace responsable por daños, pérdida de datos o fallos en el sistema causados por plugins desarrollados por terceros o modificaciones no oficiales del motor.

## 3. Uso Comercial

El uso comercial del motor DVGE está permitido bajo la licencia MIT, pero el uso de plugins específicos del ecosistema oficial puede estar sujeto a términos adicionales definidos por el autor.

## 4. Seguridad

Queda prohibido el desarrollo de plugins que contengan código malicioso, realicen telemetría no autorizada o comprometan la seguridad del sistema host. Jonatan Barón se reserva el derecho de revocar el acceso o eliminar cualquier plugin que viole estas normas.
